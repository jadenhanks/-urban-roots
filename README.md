# Urban Roots: Growing a Greener City

An educational website about urban gardening, made by Gavin McCoy for SDEV 153 Website Design and Development.

## Pages
- `index.html`: Home
- `about.html`: What Is It? (definition, comparison, four types)
- `benefits.html`: Benefits, before/after slider, fun facts
- `garden.html`: Grow a Garden mini-game
- `start.html`: Get Started steps, plant table, sources and credits

## Folders
- `css/styles.css`: shared stylesheet for every page
- `js/`: interactions (`main.js`), city drawing (`city.js`), garden game (`garden.js`)
- `images/`: original SVG illustrations and logo

All illustrations are original artwork made for this project. Facts come from the sources listed on `start.html`.
